# yusufiwt brand mark

The mark is a small decision-flow `y`: two branches converge into one path, while
three terminal dots represent choices and outcome. It is intentionally geometric
and remains recognizable at 16 px.

- Background: `#071426` / `#102B4D`
- Cyan branch: `#35D9FF`
- Violet branch: `#A66BFF`
- Merge color: `#7485FF`
- Clear space: at least one terminal-dot diameter

`yusufiwt-mark.svg` is the canonical full-color source and
`yusufiwt-glyph.svg` is the transparent symbol. The SwiftUI reproduction lives
in `Apps/Shared/YusufiwtBrandMark.swift`. Regenerate platform PNG app icons with:

```sh
swift Scripts/generate_brand_assets.swift
```
