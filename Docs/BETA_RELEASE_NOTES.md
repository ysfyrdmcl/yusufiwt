# AgentControl 1.0 beta release notes

AgentControl is a native, local-first operations center for Codex, Claude Code,
Gemini CLI, and generic monitoring hooks. The beta includes the macOS menu bar,
floating panel, dashboard/inbox, provider-authoritative approvals, local rules
and diagnostics, and an optional end-to-end encrypted iPhone/watch companion.

Highlights:

- Managed Codex and normalized hooks with monitor-only unknown-version fallback.
- Success only after provider acknowledgment.
- Local analytics, retention, recovery, and redacted diagnostic export.
- Encrypted relay, notification actions, Live Activities, widgets, and Watch.
- Signed release pipelines, SBOM/checksums/dSYMs, operational metrics,
  emergency controls, and account deletion.

Before reporting a problem, export and review a redacted report. Prompt text,
source, commands, paths, terminal output, and secrets should never be attached.
See `Docs/KNOWN_ISSUES.md` and `Docs/ADAPTER_COMPATIBILITY.md`.
