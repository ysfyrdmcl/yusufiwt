# Support

Contact: support@agentcontrol.app

Include app version/build, OS, provider/version, approximate time/timezone, and
reproduction steps. Export and inspect the macOS redacted diagnostic report if
comfortable. Never send prompts, source, terminal output, full commands/paths,
access/signing/APNs tokens, or secret answers.

For outages, try local-only mode and open iPhone for authoritative pending fetch.
Use `SECURITY.md` for security reports. Account deletion is available in iPhone
Settings and described in `Docs/DATA_DELETION.md`.
