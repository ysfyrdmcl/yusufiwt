# Known issues — 1.0 beta

- Provider majors outside the published matrix intentionally become
  monitor-only until fixture-based compatibility ships.
- APNs is advisory. During an Apple outage, notifications/Live Activities may
  be delayed; opening the companion performs authoritative pending fetch.
- Exact terminal-pane navigation may require one-time Automation or
  Accessibility permission. Monitoring and decisions need no Screen Recording.
- The native desktop is macOS-only; Linux can host the relay, but no Linux or
  Windows desktop client ships in 1.0.
- Protected notarization, clean-Mac update, TestFlight, physical iPhone/Watch,
  and production APNs evidence must be recorded for the exact stable candidate.
